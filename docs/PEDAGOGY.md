# Pedagogy

## 1. 教学总原则

Kana 采用任务 / Can-do 驱动的课程设计：先定义学习者在真实场景中需要完成的事情，再引入完成任务所需的声音、词汇、表达、语法和文字。

课程不以 JLPT 语法顺序直接组织，但会维护与 JLPT 能力点的映射，用于阶段测评。

## 2. 中文母语者专门设计

### 2.1 利用汉字优势，但阻止错误迁移

汉字词需要显式标记中日关系：

- 同形同义；
- 同形近义；
- 同形异义；
- 日语特有用法；
- 中文可快速联想但读音必须重新建立。

每个需要提醒的词都应该有 `zh_note`，不能依赖老师临场补充。

### 2.2 声音先于字形

中文学习者容易在看到汉字后用中文语音建立记忆，因此核心词和表达需要包含“只听不看”的活动。

Stage 0 必须系统覆盖：

- 五元音；
- mora（拍）的意识；
- 清音 / 浊音 / 半浊音；
- 拨音 ん；
- 促音 っ；
- 长音；
- 拗音；
- 片假名长音符号；
- 常见音辨混淆。

### 2.3 罗马音是脚手架，不是目标

罗马音只允许在最初阶段辅助发音。课程系统必须支持按阶段逐渐隐藏罗马音，避免形成长期依赖。

### 2.4 不做逐词中文翻译思维

课程需要尽早建立以下意识：

- 日语常省略主语；
- 助词表达关系，不等于中文介词逐字替换；
- 日语的信息结构和中文不同；
- 固定表达优先按整体理解；
- 同一句 `大丈夫です` 会随语境改变功能。

## 3. 每课固定教学流程

默认 Lesson Pipeline：

1. **Can-do**：一句话说明学完能做什么；
2. **Context**：给出真实场景和人物关系；
3. **Listen first**：第一遍优先听，不立即给全部文字；
4. **Comprehension**：只检查大意，不先考细节；
5. **Reveal**：显示日文、假名和必要中文；
6. **Notice**：让学习者注意本课关键语言现象；
7. **Explain**：中文解释词汇、语法和语用；
8. **Chinese learner note**：指出迁移优势或陷阱；
9. **Controlled practice**：小范围练习；
10. **Perception practice**：听辨、长度、语音区分；
11. **Production**：从识别转向主动输出；
12. **Performance task**：完成真实小任务；
13. **Can-do check**：用户确认是否能独立完成；
14. **Review scheduling**：把相关技能进入记忆系统。

不是每一课都必须机械呈现 14 个页面，但教学逻辑必须完整。

## 4. 练习设计规则

### 4.1 不允许只有选择题

每个重要概念至少覆盖两种不同方向，例如：

- 日文 → 中文识别；
- 中文 / 场景 → 日语主动回忆；
- 音频 → 含义；
- 音频 → 假名；
- 句子缺口 → 正确形式；
- 场景 → 完成一句表达。

### 4.2 错误必须可解释

错误反馈至少包含其中一项：

- 正确答案；
- 为什么；
- 学习者可能混淆的点；
- 对比例句；
- 是否需要加入额外复习。

禁止只显示红色叉号。

### 4.3 练习难度递进

推荐顺序：

```text
识别 → 提示回忆 → 无提示回忆 → 组合 → 场景输出
```

## 5. 词汇教学

新词优先出现在对话 / 场景中，随后抽取讲解。

词条应至少包含：

- lemma；
- reading；
- 中文义；
- 常见语境；
- 音频；
- 示例；
- 中文学习者提醒（如需要）；
- 当前课程中的功能。

不追求单课塞入大量孤立词汇。基础阶段默认每课 6–12 个真正需要主动掌握的新词 / 表达，具体由内容 lint 给出警告而非硬编码阻止。

## 6. 语法教学

语法不是公式表。每个 grammar point 应回答：

1. 它在这个场景里解决什么表达问题？
2. 形式是什么？
3. 中文学习者最容易怎么误解？
4. 与已经学过的结构有什么区别？
5. 能不能在真实任务中用出来？

## 7. 汉字教学

初学阶段原则：**词优先于孤立汉字**。

以 `学校（がっこう）` 为学习单元时，同时建立：

- 整词意义；
- 日语读音；
- mora 结构；
- 与中文“学校”的正迁移；
- 促音和长音的发音提醒。

单独的音读 / 训读表只作为参考信息，不作为主学习流程。

## 8. 掌握度

一个概念不能只有 `known: bool`。

至少区分：

- recognition；
- listening；
- reading；
- production；
- usage。

例如用户可能认识 `食べる`，但听不出来、说不出来，或不会在过去式中使用。系统必须允许这些能力独立变化。

## 9. 课程质量门槛

任何正式 Lesson 在进入稳定内容包前，应满足：

- 有明确 Can-do；
- 有真实场景；
- 有输入材料；
- 有中文讲解；
- 有主动输出；
- 有可解释错误反馈；
- 有至少一个最终任务；
- 关键中文学习者误区已检查；
- 所有引用音频和概念存在；
- license/source metadata 完整。
