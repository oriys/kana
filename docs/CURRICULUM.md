# Curriculum

## 总体路线

```text
Stage 0  声音与假名
   ↓
Stage 1  A1 生存与基础互动
   ↓
Stage 2  A2 日常生活与连续表达
```

第一阶段开发聚焦 Stage 0 + A1 前两个 Unit。

## Stage 0 — 声音与假名

目标不是背完五十音表，而是建立“声音 ↔ 假名 ↔ 输入”的稳定映射。

### F0.0 日语声音的基本单位

Can-do：能理解日语不是按汉字或拼音音节切分，而是按拍（mora）感知节奏。

### F0.1 あ行

- あ い う え お
- 日语五元音
- 不直接套用汉语拼音音值

### F0.2 か行 / さ行

- かきくけこ
- さしすせそ
- 特别注意 し

### F0.3 た行 / な行

- たちつてと
- なにぬねの
- 特别注意 ち / つ

### F0.4 は行 / ま行 / や行

### F0.5 ら行 / わ行 / ん

- ら行不是普通中文 l / r 的简单替换
- ん 的位置变化先建立感知，不要求理论化

### F0.6 浊音与半浊音

### F0.7 拗音

- きゃ / きゅ / きょ 等
- 防止拆成两个独立拍

### F0.8 促音

- っ
- 拍长度
- 最小对立听辨

### F0.9 长音

- こう / おう / えい 等基础规律
- 长短差异会改变词义

### F0.10 片假名

先复用已建立声音系统，再学习第二套字形。

### F0.11 外来语与长音符

### F0.12 综合听辨

### F0.13 假名毕业任务

完成：

- 基础假名读取；

# Stage 1 — A1

## Unit 1 初次见面

### A1.U1.L1 第一次见面

Can-do：能说出姓名和来自哪里，并完成基础寒暄。

核心表达：

- はじめまして
- ～です
- 中国から来ました
- よろしくお願いします

教学重点：

- 固定寒暄整体学习；
- `です` 的基本功能；
- 日语经常省略主语；
- 不需要每句都说 `私は`。

### A1.U1.L2 你叫什么名字？

Can-do：能询问并确认对方姓名。

### A1.U1.L3 哪个国家 / 哪里人

Can-do：能询问来自哪里并回答。

### A1.U1.L4 职业与身份

Can-do：能简单说明学生、公司职员等身份。

### A1.U1.L5 Unit Task

任务：完成一段 30–45 秒的首次见面对话。

## Unit 12 A1 综合任务

综合完成一组生活任务：

1. 和陌生人认识；
2. 购物；
3. 找地方；
4. 点餐；
5. 安排行程；
6. 描述昨天发生的事。

最终评估同时记录 Can-do 与语言知识，不只给总分。

## 内容节奏原则

- 每课目标优先保持单一；
- 主动新词通常控制在约 6–12 个；
- 新语法通常 1–3 个核心点；
- 复用旧内容必须明显多于新内容；
- 一个 Unit 结束必须有综合任务；
- 学过的语言在后续场景反复自然出现。
